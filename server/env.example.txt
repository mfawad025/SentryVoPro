# 1. Create two products in your Lemon Squeezy dashboard:
#      "Single Keyword/Account"      — $50/month
#      "Multiple Keywords/Accounts"  — $100/month

# 3. Dashboard > Settings > Webhooks > add https://<your-backend>/api/lemonsqueezy/webhook
#    subscribed to at least: order_created, subscription_created
#    Copy the signing secret it gives you:
LEMONSQUEEZY_WEBHOOK_SECRET=your_webhook_signing_secret
# 4. First-time-customer discount — 40% off first payment on BOTH plans
#    ($50→$30, $100→$60). Since it's the same percentage for both, one
#    discount code covers everything:
#      Dashboard > Discounts > New Discount
#        - "FIRST40": 40% off, store-wide (all products), restricted to
#          "New customers only"
#    Put the discount's CODE (not its internal ID) here:
LEMONSQUEEZY_FIRST_ORDER_DISCOUNT_CODE=your_discount_code

# 3. Copy its Search Engine ID (cx) below
